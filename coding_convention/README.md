# Homestay Coding Convention

- `CODING_CONVENTION.md`: Quy ước triển khai Backend Spring Boot/MySQL và Frontend ReactJS/Vite. Backend hiện dùng Spring Data JPA/Hibernate, Entity, Repository và `@Transactional`.
- `.editorconfig`: Quy ước định dạng file cơ bản.

Đọc convention cùng `README.md`, tài liệu nghiệp vụ/API cần thiết và `database/homestay-database.sql` trước khi code. Giữ cách tổ chức và thư viện đang có; không chuyển sang JDBC hoặc đổi kiến trúc nếu chưa được yêu cầu.
